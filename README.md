# Biosignal Analytics

This umbrella repository links three independent projects on [EEG Analysis](https://github.com/mmhapp/EEG-Analysis), [BP and EEG Analysis](https://github.com/mmhapp/BP-and-EEG-Analysis), and [ECG, PCG, and SCG Analysis](https://github.com/mmhapp/ECG-PCG-and-SCG-Analysis). Projects are focused on neurological signals (EEG), cardiovascular signals (ECG, BP, PCG, SCG), and cross-modal analysis (EEG–BP). 

---

## Repositories

[EEG Analysis](https://github.com/mmhapp/EEG-Analysis) contains a MATLAB pipeline for EEG preprocessing, ICA, ERP analysis, and statistical testing. Analyses neural correlates of auditory awareness: aware vs. unaware perception of tones.

[BP and EEG Analysis](https://github.com/mmhapp/BP-and-EEG-Analysis) contains a Jupyter pipeline for simultaneous EEG and BP signal analysis. Cleans and segments signals based on stimuli markers, extracts EEG frequency bands, and computes Spearman correlations between neural and cardiovascular features.

[ECG, PCG, and SCG Analysis](https://github.com/mmhapp/ECG-PCG-and-SCG-Analysis) contains a Jupyter notebooks for ECG, PCG, and SCG analysis. Includes multiple filtering techniques, peak detection, and feature extraction methods for cardiovascular biosignals.
