# Biosignal Analytics

This umbrella repository links projects on [BP and EEG Analysis](https://github.com/mmhapp/BP-and-EEG-Analysis), [ECG, PCG, and SCG Analysis](https://github.com/mmhapp/ECG-PCG-and-SCG-Analysis), and [EEG Analysis](https://github.com/mmhapp/EEG-Analysis). Projects are on cardiovascular biosignals (ECG, PCG, SCG), neurological biosignals (EEG), and cross-modal analysis (EEG–BP). 

---

## Repositories

[BP and EEG Analysis](https://github.com/mmhapp/BP-and-EEG-Analysis) contains a Jupyter pipeline for simultaneous EEG and BP signal analysis. Signals are filtered and segmented based on stimuli markers, frequency bands are extracted, and Spearman correlations between features are computed.

[ECG, PCG, and SCG Analysis](https://github.com/mmhapp/ECG-PCG-and-SCG-Analysis) contains a Jupyter notebooks for ECG, PCG, and SCG analysis. It Includes filtering, peak detection functions, spectral analysis, and feature extraction methods for cardiovascular biosignals.

[EEG Analysis](https://github.com/mmhapp/EEG-Analysis) contains a MATLAB pipeline for EEG preprocessing, ICA, ERP analysis, and statistical testing. In addition, a statistical analysis with t-test is done: aware vs. unaware perception of tones.
